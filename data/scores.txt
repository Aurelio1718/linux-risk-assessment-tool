# data/scores.txt - Risk table for ra-tool: likelihood, impact, risk
# description and recommended action per check.
#
# Format: one entry per line, fields separated by '|':
#   source | id | impact | likelihood | risk | action
#   - impact, likelihood: integers 1-5 (scales in README "Risk method");
#     '-' keeps the module's default score (rkhunter and native checks
#     score themselves, e.g. known false positives get a low score)
#   - risk: what can go wrong, in one sentence
#   - action: what to do; '-' or empty uses the tool's own suggestion
#   - an entry applies to every finding with that source and ID
# Checks not listed here keep the module default score:
#   Lynis warning 3/3, Lynis suggestion 2/2 (basis "default" in the report).
#
# Lynis test descriptions: https://cisofy.com/lynis/controls/<ID>/
